# Architecture: MiroFish Swarm Core\n\n## Overview\n\nMulti-agent swarm orchestrator for decentralized trading and investment decision-making. Each agent is Claude-powered with specialized analysis capabilities; consensus voting determines trade execution. Real-time dashboard aggregates Mirofish intel, agent conviction, and execution results.\n\n## Component Dependency Graph\n\n```\nMain (docs + scripts)\n  ├─ Orchestrator (foundation)\n  │   ├─ Multi-Agent System (depends on orchestrator dispatch)\n  │   │   ├─ Consensus Engine (voting + confidence calculation)\n  │   │   └─ Intel Aggregation (Mirofish data integration)\n  │   └─ Broker Adapters (depends on consensus votes)\n  │       └─ Dashboard (real-time state + decision visualization)\n```\n\nBuild order (enforce strictly):\n1. **Phase 1:** Architecture documentation + TypeScript stubs (ARCHITECTURE.md, QUICKSTART.md, types/)\n2. **Phase 2:** Implement Orchestrator → `feature/swarm-core`\n   - Core dispatch loop, state management, event bus\n   - Multi-agent registration and lifecycle\n3. **Phase 3:** Implement Multi-Agent System + Consensus → `feature/swarm-agents`\n   - Claude integration per agent, specialized analysis\n   - Voting logic, conviction calculation\n   - Mirofish data aggregation\n4. **Phase 4:** Implement Broker Adapters → `feature/swarm-adapters`\n   - Alpaca, Interactive Brokers, Kraken, Zerodha adapters\n   - Execution, balance tracking, order history\n5. **Phase 5:** Implement Dashboard → `feature/swarm-dashboard`\n   - Real-time signal visualization\n   - Agent breakdown + consensus result\n   - Execution history + performance metrics\n\n## Phase 1: Architecture & Stubs (COMPLETE)\n\n**Files:**\n- `ARCHITECTURE.md` (this file)\n- `QUICKSTART.md` — Local dev setup, run first signal\n- `src/types/index.ts` — Shared TypeScript interfaces\n- `src/types/orchestrator.ts` — Orchestrator contracts\n- `src/types/consensus.ts` — Consensus + voting contracts\n- `src/types/adapters.ts` — Broker adapter interface\n- `src/types/mirofish.ts` — Mirofish intel data models\n\n**Status:** Documentation + type stubs only. `src/mirofish/aggregator.ts` — Mirofish swarm intel integration\n\n**Key Classes:**\n```typescript\nexport abstract class Agent {\n  id: string;\n  model: string; // \"claude-3-5-sonnet-20241022\" or similar\n  specialty: string; // \"fundamental\", \"technical\", etc.\n  \n  abstract async analyze(signal: InvestmentSignal): Promise<Vote>;\n  \n  // Safety checks\n  async validateSignal(signal: InvestmentSignal): Promise<boolean>;\n  \n  // Reasoning / explainability\n  getLastAnalysis(): AnalysisResult;\n}\n\nexport class ConsensusEngine {\n  agents: Agent[];\n  votingThreshold: number; // 0.5 = simple majority, 0.66 = 2/3 majority\n  \n  async vote(signal: InvestmentSignal): Promise<VotingResult>;\n  \n  // Conviction = confidence score based on vote agreement + agent confidence\n  calculateConviction(votes: Vote[]): ConvictionResult;\n}\n\nexport class MiroFishAggregator {\n  // Fetch + cache swarm intel\n  async getSwarmSignals(symbol: string): Promise<SwarmSignal[]>;\n  async getConsensusScore(symbol: string): Promise<number>; // 0–1\n  async getTrendingAssets(): Promise<Asset[]>;\n  \n  // Feed into agent analysis\n  enrich Signal with swarm context\n}\n```\n\n**Voting Logic:**\n- Each agent submits a `Vote: { approve: boolean, confidence: 0-1, reasoning: string }`\n- Consensus threshold (default 66%) determines approval\n- Conviction = (% approved votes) × (avg agent confidence)\n- Example: 5 agents, 4 approve (80%), avg confidence 0.75 → conviction = 0.6\n\n**Tests:** `src/__tests__/consensus.test.ts`, `src/__tests__/mirofish.test.ts`\n\n**Depends on:**
